# MangaReader — Rust & Upscaler Edition

Нативное десктопное приложение для чтения манги, манхвы и маньхуа на **Rust (`tao` + `wry`) + React + TypeScript** со встроенным многопоточным апскейлером изображений, OCR-автопереводом страниц и агрегацией каталогов.

---

## Основные возможности

### 1. Нативное ядро на Rust (`src-rs/main.rs`)
- **Лёгкий и быстрый клиент**: размер исполняемого файла `~3.8 МБ`, мгновенный запуск через системный WebView2.
- **Умный сетевой прокси (`mhttp://`)**:
  - Приоритет IPv4 для исключения таймаутов соединения.
  - Автоматический обход гео-блокировок и защит (включая работу с `MangaDex`, `MangaLib`, `Remanga`, `ManhwaTop`, `MangaClash`, `Toonily` даже при активном VPN/TUN-интерфейсе).
- **Многопоточный дисковый кэш (`mimg://`)**: кэширование оригинальных и улучшенных страниц в `%LOCALAPPDATA%\manga-reader-rust\img-cache`.

### 2. Встроенный апскейлер манги (Rust + GPU Shaders)
Переключение режима прямо во время чтения или в настройках:
- **Выкл (Оригинал)** — исходное качество без обработки.
- **Anime4K Fast (Шейдер)** — реконструкция контуров и линий в реальном времени.
- **Rust Lanczos3 2x + Sharp** — двукратное масштабирование `Lanczos3` + контурная резкость `unsharpen` на пуле потоков `rayon`.
- **Rust Manga HQ (Денойз + 2x)** — параллельный 3×3 билатеральный фильтр подавления JPEG-артефактов + повышение контраста контуров + 2x `Lanczos3`.
- **Чистая тушь (B&W Контраст)** — адаптивное выбеливание серого фона сканов и углубление чёрной туши и шрифтов.
- **AI Real-ESRGAN / Waifu2x (Vulkan)** — поддержка внешних нейросетевых Vulkan-модулей в папке `upscaler/` с автоматическим фоллбэком на `Rust Manga HQ`.

### 3. Автоперевод страниц и описаний (OCR + Translate)
- **Нативный Windows WinRT OCR (`Windows.Media.Ocr`)**: распознавание текста в репликах/облачках на странице и объединение строк внутри бабблов.
- **Автоперевод на лету (`RU`, `EN`, `ES`, `DE`)**: наложение переведённых облачков поверх страницы в ридере (при наведении курсора показывается оригинал).
- **Перевод описания**: кнопка перевода иноязычного описания тайтла в один клик.

### 4. Единый каталог без дубликатов и удобная библиотека
- **Дедупликация тайтлов**: каждая манга в каталоге и поиске отображается в 1 экземпляре, а на странице тайтла можно свободно переключать сайт-источник (`MangaLib`, `Remanga`, `MangaDex`, `SlashLib`, `HentaiLib`, `ManhwaTop`, `MangaClash`, `Toonily`).
- **Мультивыбор жанров и источников**: раскрывающиеся панели выбора нескольких жанров и сайтов, живые подсказки при вводе в поиске.
- **Раздельные фильтры `18+` и `Хентай`**: разграничение взрослой сейнен/этти манги (`18+`) и откровенного контента (`Hentai`).
- **Отслеживание прочитанных глав и скачивание**: пометка прочитанных глав, скачивание отдельных глав или всей манги в папку `Downloads\MangaReader\` и архивы `.cbz`.
- **Двуязычный интерфейс (`RU / EN`)**: полный перевод интерфейса и автоматический выбор русских либо английских названий тайтлов.

## Сборка из исходников

### Требования
- **Node.js** 18+
- **Rust** (`rustup`, `cargo`, `x86_64-pc-windows-msvc`)

### Команды
```bash
# Установка фронтенд-зависимостей
npm install

# Сборка фронтенда и компиляция нативного Rust-бинарника
npm run build

# Готовый файл:
# target/release/manga-reader-rust.exe
```
